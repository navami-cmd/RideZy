A ride-booking web app in a single `index.html`. No framework, no build step.

## Stack

![HTML5](https://img.shields.io/badge/HTML5-0b1f3f?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-3f6fa8?style=flat-square&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-0b1f3f?style=flat-square&logo=javascript&logoColor=white)
![Leaflet](https://img.shields.io/badge/Leaflet-3f6fa8?style=flat-square&logo=leaflet&logoColor=white)

- Vanilla HTML, CSS and JavaScript
- [Leaflet](https://leafletjs.com) for the map
- Esri / OpenStreetMap tiles, Nominatim (search), OSRM (routing), Open-Meteo (weather)

No API keys required.

## Run locally

1. Clone or download this repository.
2. In VS Code, right-click `index.html` and choose **Open with Live Server**.

An internet connection is needed for the map, place search and fonts.

## Notes

Drivers, payments and SOS are simulated.
